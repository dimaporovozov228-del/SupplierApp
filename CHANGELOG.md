# Изменения версии 4.0

- Добавлены формы CartForm и OrderDetailsForm.
- Добавлены ShoppingCart и CartItem: одинаковые товары объединяются, суммы округляются по каждой позиции до двух знаков методом ToEven.
- Каталог: поиск, сортировка, выбор количества, счётчик и сумма корзины, предупреждение при выходе.
- AppDatabase.CreateOrders сохраняет все позиции одной транзакцией. Исходная CreateOrder сохранена и использует тот же код записи.
- История: фильтр статуса, итог без отменённых, полный адрес в карточке, отмена только своего нового заказа параметризованным UPDATE.
- Экспорт текущего списка в CSV: UTF-8 с BOM, разделитель «;», экранирование кавычек, переносов строк и потенциальных формул.
- Единая палитра и заголовки всех форм; каталог, корзина и история изменяют размер вместе с окном.
- Вход: показ/скрытие пароля; проверка и создание пароля выполняются в фоне, чтобы окно оставалось отзывчивым. Ошибка дублирования логина обрабатывается по SQLState 3022, который возвращает Jet на Windows.
- Исправлена запись дробного количества: параметр Currency точно передаёт допустимые три знака в поле Access DECIMAL(18,3). Decimal/Numeric-параметр Jet 4.0 возвращал ошибку несовпадения типов.
- Решение возвращено к x86; версия сборки 4.0.0.0. Файл базы и её схема не изменены.
- Добавлены воспроизводимые интеграционные проверки Tests/Run-SmokeTests.ps1 на копии базы.

Совместимость: старые пользователи и заказы доступны без миграции. В корзине каждая позиция оформляется отдельным заказом с собственным номером, все позиции сохраняются атомарно.
