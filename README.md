# SupplierApp — Ваш любимый поставщик

Учебный магазин на C# Windows Forms, .NET Framework 4.8, платформа **x86**. Данные хранятся в Microsoft Access `SupplierApp.mdb`, доступ — через OleDb. Актуальная версия: **4.0**.

## Что появилось в версии 4

- Каталог в виде таблицы: поиск по названию без учёта регистра и сортировка по названию или цене.
- Новая форма **«Корзина»**: несколько товаров, дробное количество, объединение одинаковых товаров, изменение количества и удаление позиций, пересчёт суммы.
- Оформление всей корзины одной транзакцией. Каждая товарная позиция получает отдельный номер заказа. Если товар недоступен или цена изменилась, ни одна позиция не сохраняется; корзина остаётся для исправления.
- Обновлённая история: фильтр по статусу, сумма без отменённых заказов, новая **карточка заказа** с полным адресом, отмена собственных заказов со статусом «Новый».
- Экспорт показанных заказов в CSV с кириллицей для Excel. Текстовые поля защищены от выполнения формул.
- Единое оформление: тёмные заголовки, зелёные акценты, понятные кнопки, крупные таблицы. Каталог, корзина и история поддерживают изменение размера окна.
- Кнопка показа пароля на входе; вход и регистрация не блокируют окно во время проверки пароля. Исправлена обработка занятого логина и запись дробного количества через Jet 4.0.

Всего в приложении семь форм: вход, регистрация, каталог, оформление одного товара (сохранено для учебного примера), история, корзина и карточка заказа. Основной сценарий покупки в версии 4 проходит через корзину.

## Запуск

1. Откройте `SupplierApp.sln` в Visual Studio с компонентами «Разработка классических приложений .NET» и .NET Framework 4.8 Targeting Pack.
2. Выберите `Release | x86` или `Debug | x86`, соберите решение.
3. Запустите проект клавишей F5 либо откройте `SupplierApp\bin\Release\SupplierApp.exe`. В локальной папке после сборки можно использовать `Запустить SupplierApp.cmd`.
4. Тестовый вход: **student / Student123!**.

Рядом с exe обязательны `SupplierApp.exe.config` и папка `Database` с `SupplierApp.mdb`. Программа использует локальную базу из каталога запуска. Исходная база копируется в bin только при первой сборке: повторная сборка не стирает пользователей и заказы.

Используется 32-разрядный `Microsoft.Jet.OLEDB.4.0`. Для ACE укажите установленный 32-разрядный провайдер в `SupplierApp\App.config`. Сведения о схеме и совместимости: [DATABASE.md](DATABASE.md).

## Как пользоваться

Введите часть названия в поле поиска, выберите товар и количество, нажмите «Добавить в корзину». Повторите для других товаров, откройте корзину, проверьте количество и укажите адрес доставки (5–255 символов). После оформления откройте «Мои заказы».

Корзина хранится в памяти до закрытия каталога. Перед выходом с непустой корзиной программа предупреждает о её очистке. Адрес последнего успешного оформления подставляется при следующей покупке в текущем сеансе. Сохранённые заказы и пользователи остаются в Access между запусками.

Отмена не удаляет заказ: статус меняется на «Отменён». Сумма в истории учитывает показанные фильтром заказы, кроме отменённых. Экспорт сохраняет текущий отфильтрованный список.

## Проверка на Windows

На Windows выполнены сборки Release/Debug x86 и 27 интеграционных проверок Jet/OleDb на отдельной копии базы. Проверяются вход и регистрация, занятый логин, корзина и округление, дробное количество, полный откат при ошибке позиции, сохранение адреса, отмена только своего нового заказа, экспорт и защита CSV. Окна дополнительно проверены при запуске.

Повторить проверки из PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tests\Run-SmokeTests.ps1
```

Скрипт собирает Release x86, создаёт `Tests\bin\Fixture.mdb` из исходной базы и работает только с этой копией. Результаты находятся в `Tests\bin` и не попадают в Git. Оригинальная и рабочая база приложения тестами не изменяются.
