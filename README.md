# SupplierApp — Ваш любимый поставщик

Учебный проект C# Windows Forms, .NET Framework 4.8, Visual Studio, платформа x86.

## Этапы
- v1.0-forms — пять форм с полями, без кнопок и обработчиков.
- v2.0-navigation — кнопки, переходы, регистрация, вход, каталог и заказы в Access.
- v3.0-design — оформленный интерфейс, все функции второго этапа.

Это три последовательных учебных снимка, подготовленных из существующего проекта.

Откройте SupplierApp.sln. Нужна рабочая нагрузка Visual Studio «Разработка классических приложений .NET» и .NET Framework 4.8 Targeting Pack.

Переключить этап можно командой git switch --detach ИМЯ_ТЕГА.
Вернуться к последней версии — git switch main.

В первом этапе все окна открываются для просмотра одновременно. Закройте все окна, чтобы завершить приложение.

Во втором и третьем этапах используется Access .mdb и OleDb x86. Тестовый вход student / Student123!.
Файл Database/SupplierApp.mdb копируется в bin только при первом запуске сборки.
Для использования ACE настройте App.config по инструкции DATABASE.md.
